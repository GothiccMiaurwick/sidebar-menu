📁 sidebar-menu
A responsive and collapsible sidebar built with pure HTML and CSS.
Crafted to integrate seamlessly into modern layouts, this sidebar provides a clean, adaptable navigation experience across different screen sizes.

✨ Features:
📱 Responsive design: Optimized for mobile, tablet, and desktop views.

🎯 Collapsible sidebar: Expands and contracts smoothly to enhance user interaction.

💡 Clean and functional UI: Ideal for projects that need a clear structure without relying on external frameworks.

A great starting point for dashboards, admin panels, or any web app requiring structured sidebar navigation.

📁 sidebar-menu
Un sidebar responsive y colapsable desarrollado con HTML y CSS puro.
Diseñado para integrarse fácilmente en cualquier layout moderno, este menú lateral ofrece una navegación limpia y adaptable para distintos tamaños de pantalla.

✨ Características:
📱 Responsive: Se adapta a dispositivos móviles, tablets y pantallas de escritorio.

🎯 Sidebar colapsable: Se expande y contrae para ofrecer una experiencia de usuario más dinámica.

💡 Diseño limpio y funcional: Ideal para proyectos que buscan una estructura clara sin depender de frameworks externos.

Perfecto como punto de partida para dashboards, paneles de administración o cualquier aplicación web que necesite una navegación lateral estructurada.
